Impostazioni

Condividi prova a inviare il file PDF a iPadOS. Se non vedi le app per PDF, usa Visualizza PDF (apertura diretta del PDF) e poi Condividi dal visualizzatore; oppure usa Salva PDF e aprilo dall’app File → Condividi. La PWA non può forzare la comparsa di Piascore.

Backup

Fai periodicamente un backup su iCloud Drive o nell'app File. I dati delle PWA possono essere rimossi da iPadOS.

Aggiornamenti

Controlla se è disponibile una nuova versione su GitHub Pages. I PDF salvati nell’archivio non vengono cancellati dall’aggiornamento.

Informazioni

Tutti i tuoi PDF sono archiviati localmente su questo dispositivo. Le librerie di elaborazione vengono scaricate alla prima apertura online. «Rileva parti» analizza le intestazioni con testo PDF e OCR locale. Su spartiti impaginati diversamente possono servire correzioni manuali; verifica sempre le pagine selezionate.
